# 🚀 Pyramakerz R&D Reporting System

A comprehensive Google Apps Script based reporting system for engineering teams.

## 📋 Features
- Daily task submission for engineers
- Manager dashboard with analytics
- CTO project creation and management
- Deadline tracking and notifications

## 🏗️ Architecture
- **Frontend**: Modular HTML components with CSS/JS
- **Backend**: Google Apps Script services
- **Database**: Google Sheets as data store

## 🔧 Setup
1. Clone this repository
2. Configure Google Apps Script project
3. Deploy using CLASP or manual upload
